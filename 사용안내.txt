마인드스토리 대표 홈페이지

1. 내 컴퓨터에서 열기

내려받은 mindstory-homepage.zip의 압축을 풀어 파일들을 아래 폴더에 넣으세요.
C:\Users\UserK\Desktop\PLATFORM\마인드스토리홈페이지

위 폴더 안에 index.html, special-education.html, styles.css, special.css, site-config.js, site.js, assets 폴더가 함께 있으면 됩니다.
index.html을 더블클릭하면 Chrome 또는 Edge에서 홈페이지가 열립니다.
별도의 프로그램 설치나 명령어 입력은 필요 없습니다.

2. 현재 연결된 사이트

온라인 교육: https://edu.mindstory.kr/ (평생교육원 새 주소)
AI 그림동화: https://story.mindstory.kr/
공식 블로그: https://blog.naver.com/sanj2100

서비스 카드를 누르면 해당 사이트가 새 창에서 열립니다.
로컬 화면은 인터넷 없이 열 수 있지만, 연결된 사이트를 이용하려면 인터넷이 필요합니다.
기존 사이트의 로그인·수강·창작 기능은 해당 서비스에서 이용합니다.

3. 연결 사이트와 문의 정보 바꾸기

site-config.js 파일을 메모장 또는 코드 편집기로 열면 사이트 이름, 설명, 주소, 전화번호, 이메일을 수정할 수 있습니다.
서비스의 link 항목에는 https://로 시작하는 전체 주소를 입력하세요.
항목 사이의 쉼표와 문자열 양쪽 따옴표는 유지하세요.
수정한 뒤 저장하고 홈페이지에서 새로고침(F5)을 누르세요.
화면의 다른 문구는 index.html에서, 색상과 배치는 styles.css에서 수정합니다.

4. 파일 구성

index.html               홈페이지 화면
special-education.html   학교폭력 특별교육 안내 페이지
styles.css               디자인과 모바일 화면
special.css              특별교육 페이지와 메인 배너 디자인
site-config.js   연결 서비스·전화번호·이메일 설정
site.js          모바일 메뉴·서비스 표시·연락처 복사
assets           일러스트, 아이콘, 글꼴 및 글꼴 이용허락 안내

3-1. 학교폭력 특별교육 코너

상단 메뉴의 '학교폭력 특별교육', 메인 화면의 '특별교육 안내 보기' 버튼, 하단 메뉴에서 special-education.html로 이동합니다.
교육 내용·자주 묻는 질문 문구는 special-education.html에서 수정합니다.
교육시간과 비용은 학교의 조치·의뢰 내용을 확인한 뒤 개별 안내하는 것으로 작성했습니다.
'2026년 광주광역시교육청 학교폭력 특별교육 이수기관 지정' 문구는 실제 지정 공고 내용과 일치하는지 확인 후 게시하세요.

5. 확인 범위

AI 그림동화 주소는 기존에 알려주신 주소를 연결했습니다. 이번 작업에서는 해당 외부 사이트의 실제 동작을 확인하지 못했습니다.
공식 블로그 주소는 기존 마인드스토리 홈페이지의 공식 링크를 기준으로 연결했습니다.
이메일은 기존 기관 프로그램 안내와 AI 그림동화 홍보자료에 공개된 주소를 사용했습니다.
대표 홈페이지는 자체 회원가입·신청·결제 정보를 수집하지 않습니다.

폴더에서 파일을 여는 것만으로 기존 mindstory.kr이나 다른 도메인이 변경되지는 않습니다.
직접 운영할 도메인과 호스팅 연결은 별도의 배포 단계에서 적용합니다.
